## Collaboration Workflow

Our team follows a Git-based collaborative development workflow.

1. Each member creates a separate branch for their assigned work.
2. Each member commits changes with a meaningful commit message.
3. Each member pushes their branch to GitHub.
4. A Pull Request is created to propose changes.
5. Another team member reviews the Pull Request.
6. Approved changes are merged into the main branch.
