# Project Documentation

This directory contains documentation for the Smart Virtual Assistant project developed by our CSC10014 team at HCMUS.

## Purpose

The `docs/` folder is used to organize project documentation, track team responsibilities, and record important development decisions.

## Documentation Files

| File | Description |
|---|---|
| `README.md` | Overview of the documentation directory |
| `team.md` | Team members, responsibilities, and assigned tasks |

## Planned Documentation

As the project progresses, this directory may include:

- Project requirements and specifications
- System architecture and design
- Development progress and meeting notes
- Testing reports
- Technical decisions and implementation notes

## Collaboration Guidelines

1. Create a separate Git branch for documentation changes.
2. Write clear and understandable documentation.
3. Review changes before committing.
4. Open a Pull Request for review.
5. Merge approved changes into the main branch.
